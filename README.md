# Sistema de Reservas de Hotel — PostgreSQL

Atividade prática com procedures para cadastro de hóspedes e gestão de reservas.

## Como executar

Use PostgreSQL 11 ou superior. Execute nesta ordem: `sql/01_schema.sql`, `sql/02_procedures.sql` e `sql/03_examples.sql`. Os exemplos de alteração de dados foram preparados para serem executados uma única vez.

## Conteúdo

Implementa as questões 1 a 15: cadastro e consulta de hóspedes; criação, cancelamento, cálculo, finalização, alteração e reabertura de reservas; e confirmação com validações completas. Inclui parâmetros, variáveis, SELECT INTO, INSERT, UPDATE, IF, RAISE INFO, RAISE EXCEPTION e regras de negócio.
